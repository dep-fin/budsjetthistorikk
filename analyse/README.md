# Fremstilling av budsjetthistorikk

Denne delen skal gi Finansavdelingen i Finansdepartementet søk, analyser, sammenligninger og uttrekk av historiske budsjettforslag og budsjettvedtak.

Fremstillingen skal bruke et dokumentert datagrunnlag fra innlesningsdelen. Første analyseoppgaver, grensesnitt og eksportformater avklares med brukeren før implementering.

Se [krav](../docs/krav.md) og [ansvarsdeling](../docs/ansvarsdeling.md).
